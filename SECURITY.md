# Security Policy

## Supported Versions

The following versions of OpenStandardLibrary are currently supported with security updates:

| Version | Supported |
|---|---|
| 1.0.x (latest) | ✅ |
| < 1.0.0 | ❌ |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue in OpenStandardLibrary, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

Use GitHub's private vulnerability reporting feature:

1. Go to the [Security tab](../../security) of this repository
2. Click **"Report a vulnerability"**
3. Fill out the form with as much detail as possible

Alternatively you can email us directly at **hello@factfoundry.io** with the subject line `[SECURITY] OpenStandardLibrary`.

### What to Include

Please include as much of the following as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any proof-of-concept code if applicable
- The version(s) of OpenStandardLibrary affected
- Any suggested mitigations if known

### What to Expect

- **Acknowledgement** within 48 hours of your report
- **Status update** within 7 days with our assessment and planned timeline
- **Credit** in the release notes when the fix ships, if you'd like to be acknowledged

We aim to resolve confirmed vulnerabilities as quickly as possible. For critical issues we will prioritize an out-of-band release.

## Scope

This policy applies to the OpenStandardLibrary NuGet package (`FactFoundry.OpenStandardLibrary`) maintained in this repository.
